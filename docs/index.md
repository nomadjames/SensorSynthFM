## Why this exists
SensorSynth FM has enough design documentation, implementation detail, and research framing that the project stops being legible if everything lives only in chats, commits, and scattered markdown files.

This docs layer is meant to keep the public project understandable:
- what the near-term milestone is
- what the prototype already contains
- what is still aspirational
- what makes the design direction distinctive

## Current state
The project already contains a real AudioKit FM prototype, a real sensor layer, and an integrated sensor-to-FM test path. The current bottleneck is not inventing more features. It is activating and validating the thesis-demo lane on actual hardware.
